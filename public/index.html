Questions fréquentes sur Cryptinelhack

Les réponses courtes aux questions les plus posées sur le logiciel.

Qu'est-ce que Cryptinelhack ?

Cryptinelhack est un logiciel d'automatisation et de productivité pour Windows 10 et 11. Il réunit un studio graphique sans code, 75 modèles prêts à l'emploi, 18 types de déclencheurs, le Drop Cube pour partager en local et une télécommande Android avec Stream Deck. Le téléchargement officiel se fait depuis cette page.

Comment fonctionne le Drop Cube sans connexion Internet ?

Le Drop Cube crée un point d'accès HTTP éphémère directement sur votre carte réseau locale. Les appareils scannent le QR Code et téléchargent les documents en peer-to-peer à la vitesse maximale de votre routeur Wi-Fi sans qu'aucun octet ne parte sur le Web.

Comment collecter des devoirs d'étudiants avec le Reverse Drop Box ?

Activez le mode Collecte dans le Drop Cube et partagez le QR Code dans votre salle de cours. Les étudiants déposent leurs fichiers depuis leur navigateur smartphone ou PC. Les documents arrivent directement dans votre répertoire sélectionné sans qu'ils puissent explorer votre ordinateur.

Puis-je utiliser le Stream Deck mobile sans Wi-Fi ?

Oui. Cryptinelhack intègre un mode Bluetooth Pur (RFCOMM). Votre smartphone communique directement avec votre ordinateur en liaison Bluetooth appairée, vous permettant d'exécuter vos macros même sans connexion réseau.

Mes données personnelles ou temps d'écran sont-ils envoyés sur un serveur ?

Non. Cryptinelhack fonctionne selon un principe de souveraineté numérique totale. Le suivi d'activité, les statistiques d'utilisation, les mots de passe et les fichiers restent à 100% stockés en local sur votre disque dur.

Comment obtenir une clé d'accès individuelle ?

Renseignez votre nom et votre adresse e-mail dans le formulaire ci-dessous. Votre clé d'activation unique liée à votre empreinte matérielle (HWID) vous sera expédiée directement par e-mail depuis cryptinelhack@gmail.com.
